# 🦇 Sonar Radar Pro 6 | Developer Preview

**نسخه:** `6.0.0-preview.1` · **پلتفرم:** Telegram Bot + Mini App + VPS Agent · **مجوز:** طبق سورس اصلی

این بسته یک بازطراحی مرحله‌ای از نسخه 5.3 است. قابلیت‌های موجود و صحیح حفظ شده‌اند و تغییرات نسخه ۶ در کنار آن‌ها قرار گرفته‌اند. **تست روی VPS واقعی، اتصال به تلگرام و مهاجرت تولیدی هنوز تأیید نشده‌اند.** قبل از جایگزینی نصب اصلی، روی سرور آزمایشی نصب کنید.

## شروع سریع برای مبتدی‌ها

پیش‌نیازها: Ubuntu یا Debian مبتنی بر `systemd`، اینترنت، SSH روی VPS، توکن ربات از BotFather و شناسه عددی ادمین. برای Mini App عمومی، دامنه با HTTPS نیز لازم است.

1. فایل ZIP را روی **سرور آزمایشی** بارگذاری و استخراج کنید.
2. ترمینال SSH را باز کنید و وارد پوشه `Sonar_Radar_Pro_6.0` شوید.
3. پیش از نصب، بررسی سورس را اجرا کنید:

```bash
bash install.sh --check
```

4. نصاب را باز کنید:

```bash
sudo bash install.sh
```

5. گزینه `01` را برای نصب، یا `02` را برای بروزرسانی نصب موجود انتخاب کنید. اطلاعات تلگرام را طبق پرسش‌های برنامه وارد کنید. بعد از نصب، ربات را در تلگرام با `/start` آزمایش کنید.
6. برای پنل وب، دامنه و گواهی HTTPS را از منوی `04` پیکربندی کنید. رابط وب بدون ورود امضاشده تلگرام اجازه مشاهده داده‌ها نمی‌دهد.

**وقتی نصب قبلی وجود دارد:** نصاب ابتدا موجودی فایل‌ها، سرویس‌ها و پایگاه داده اختصاصی Sonar را بررسی می‌کند. برای نصب پاک، گزینه `14` را انتخاب کنید. این گزینه قبل از حذف، آرشیو و بکاپ می‌سازد و از شما می‌خواهد دقیقاً عبارت `DELETE SONAR DATA` را تایپ کنید. **بکاپ و تأیید صریح اجباری هستند** تا اطلاعات ارزشمند بی‌هوا حذف نشوند.

## هنگام خرابی چه کنم؟

### راه ۱: از طریق تلگرام

در ربات، وارد **👑 مرکز مدیریت ربات → 🩺 عیب‌یابی** شوید (یا دستور `/doctor`). سپس:

- **گزارش سریع سلامت**: وضعیت پیکربندی، سرویس‌ها و پورت پنل.
- **📤 ساخت و ارسال ZIP لاگ‌ها**: گزارش وضعیت و آخرین لاگ‌های ربات، پنل و نصاب + آخرین وضعیت ثبت‌شده ایجنت‌ها.
- **🛰 ZIP به‌همراه لاگ ۵ ایجنت**: تلاش برای خواندن لاگ `sonar-agent` تا ۵ سرور از طریق SSH تأییدشده. سرورهای در دسترس نبود‌ه نیز در نتیجه مشخص می‌شوند. برای حفظ سرعت، بیش از ۵ ایجنت در این مسیر خوانده نمی‌شوند.
- **مشاهده لاگ ایجنت‌ها**: وضعیت هر ایجنت و خطای ذخیره‌شده.

### راه ۲: حتی وقتی ربات از کار افتاده

```bash
sudo bash install.sh --support
```

فایل گزارش در مسیر `/var/backups/sonar-radar/sonar-support-*.zip` ذخیره می‌شود. در حین **نصب یا ارتقا** هم نصاب به‌طور خودکار برای هر تلاش، یک گزارش پشتیبانی می‌سازد (حتی اگر فرایند ناموفق باشد).

```bash
sudo bash install.sh --doctor
sudo bash install.sh --logs errors --lines 200
sudo bash install.sh --status
```

نکته: گزارش ارسالی از داخل ربات، فایل‌های لاگ اختصاصی برنامه را نیز می‌خواند. اگر دسترسی سیستم به لاگ سرویس وب محدود باشد، دستور `sudo bash install.sh --support` از ترمینال گزارش کامل‌تری از journal تولید می‌کند.

**قبل از ارسال ZIP به پشتیبانی، فایل را بررسی کنید.** سازنده گزارش، توکن‌های تلگرام، رمزها، لینک‌های کانفیگ و الگوهای رایج اطلاعات محرمانه را پنهان می‌کند؛ اما هیچ پاک‌ساز خودکاری قادر نیست تمام رمزهای ناشناخته را صددرصد تشخیص دهد. گزارش‌ها با مجوز فایل محدود (`0600`) تولید می‌شوند.

## محدودیت‌های مهم این Preview

- بروزرسانی و بازگردانی **نسخه ایجنت** به‌صورت کامل، مدیریت SSH Key از ویزارد تلگرام، Hysteria2/TUIC و موتور آپلود واقعی هنوز پیاده‌سازی کامل ندارند.
- تست‌ها برای پایداری واقعی لازم‌اند. بررسی نحوی Python و Bash و تست‌های محلی، جایگزین اتصال واقعی Telegram/SSH/WSS، مهاجرت PostgreSQL و Nginx نیستند.
- پنل وب هنوز معادل تمام عملیات SSH تلگرام نیست. بعضی عملیات حساس عمداً فقط از ربات و با کنترل دسترسی انجام می‌شوند.
- قابلیت تولید گزارش، هیچ دسترسی مستقیمی برای مدل هوش مصنوعی به سرور ایجاد نمی‌کند؛ فایل را خود مدیر ارسال می‌کند. گزارش فقط برای **تشخیص بهتر** است، نه تضمین تعمیر خودکار.
- اطلاعات سرورهای نسخه قبل برای *Upgrade* حفظ می‌شوند. نصب پاک، داده اختصاصی Sonar را بعد از بکاپ و تأیید صریح حذف می‌کند.

## تست بدون سرور

```bash
python -m pytest -q tests/test_v6_release.py
python -m compileall -q .
node --check pro_web/static/app.js
bash -n install.sh
python scripts/verify_manifest.py
```

تست یکپارچه نسخه کامل، به نصب وابستگی‌های `requirements.txt` و `requirements-web.txt` و محیط آزمایشی PostgreSQL نیاز دارد. برای انتشار نهایی، همه تست‌های پروژه و سناریوهای عملیات واقعی باید سبز باشند.

## اجزای معماری

`bot.py` اجرای ربات؛ `v6_ui.py` منوها و عیب‌یابی تلگرام؛ `diagnostics.py` بسته گزارش؛ `monitor_agent.py` ایجنت و parser سابسکریپشن؛ `tunnel_logic.py` همگام‌سازی کانفیگ؛ `database.py` PostgreSQL؛ `pro_portal.py` API امضاشده؛ `pro_web/` پنل جدید؛ `install.sh` نصب و نگهداری.

مخزن اصلی: https://github.com/Amirtn9/radarsonarplus

> توجه: نسخه ZIP تنها نسخه سورس و مستندات است و به معنای انتشار تغییرات در GitHub نیست.

### نصب مستقیم از مخزن GitHub (فقط پس از انتشار این نسخه در مخزن)

```bash
wget https://raw.githubusercontent.com/Amirtn9/radarsonarplus/main/install.sh
chmod +x install.sh
sudo ./install.sh
```

این دستور از شاخه `main` دانلود می‌کند؛ تا قبل از انتشار نسخه ۶ در GitHub، **فقط ZIP همین بسته** را نصب کنید تا تصادفاً نسخه قبلی نصب نشود.
