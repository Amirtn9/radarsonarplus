# 🦇 فهرست اصلاحات Sonar Radar Pro 5.2.3

نسخه 5.2.3 بر پایه ZIP نسخه 5.2.2 ساخته شده است. هدف: رفع ایرادهای مشخص‌شده در ممیزی، بدون بازنویسی معماری Bot، Agent یا Mini App.

| موضوع | فایل‌های اصلاح‌شده | راهکار |
|---|---|---|
| قالب callback و مجوز SSH | `server_callbacks.py`, `secure_handlers.py`, `bot_logic_mod/servers.py` | parser مشترک، توقف روی قالب مبهم، کنترل owner قبل از اقدام و استفاده از IP ثبت‌شده |
| ریست نصب | `install.sh` | تائید صریح، بکاپ قابل‌تایید، بررسی وضعیت بازگشتی و توقف در خطا |
| مجوز نصب | `install.sh` | دسترسی گروهی به سورس، حفاظت از کلیدها، و تست import واقعی با یوزر سرویس |
| جست‌وجوی پنل | `pro_web/static/app.js` | ارجاع مستقیم به input |
| Pagination Pro | `pro_handlers.py` | پشتیبانی از `**kwargs` |
| نصب دسته‌جمعی | `dispatcher.py`, `admin_panel.py` | entry point، لغو مکالمه، اعتبارسنجی پورت و ثبت بعد از نصب موفق |
| پورت ایجنت | `bot_logic_mod/servers.py` | انتخاب پورت مشترک با ثبت و نصب |
| Python ایجنت | `core.py` | یکسان‌سازی مسیر venv با نصب واقعی |
| اشتراک‌ها | `bot_logic_mod/tunnels.py`, `tunnel_logic.py` | اصلاح ترتیب owner و sub؛ حفظ ID فرزندان یکسان؛ حذف فقط لینک‌های حذف‌شده |
| پایش | `cronjobs.py`, `database.py` | ثبت تاریخچه و وضعیت، آستانه‌های تنظیم‌شده و کانال هشدار |
| لغو WebSocket | `ws_client.py` | حذف اتصال دارای پاسخ نامشخص و بازگرداندن ظرفیت به استخر |

## بررسی انجام‌شده

- اجرای تمام تست‌های آفلاین، شامل تست‌های رگرسیون جدید
- `compileall` برای سورس Python
- `bash -n` برای installer
- `node --check` برای کد پنل
- راستی‌آزمایی manifest و محتوای فایل ZIP

## محدودیت

نصب کامل روی Ubuntu تازه، تست اتصال واقعی تلگرام، migration دیتابیس PostgreSQL با داده واقعی و ثبت WSS ایجنت‌ها در این محیط اجرا نشده‌اند. روی سرور اصلی بدون snapshot تست نکنید.

**پاکسازی دیتابیس فقط پس از آرشیو و تأیید متنی انجام می‌شود و بازگردانی خودکار schema در صورت خطای بعدی نصب تضمین نشده است.**
