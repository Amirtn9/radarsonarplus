# گزارش آزمون نسخهٔ 5.3.0

تاریخ: ۱۵ اکتبر ۲۰۲۶. مبنا: آرشیو Sonar_Radar_Pro_5.2.2_Installer_Fix_GitHub_Ready2.zip. این گزارش مربوط به سورس اصلاح‌شدهٔ داخل همین بسته است.

## مجموعهٔ تست پروژه

فرمان: `python -m pytest -q tests`

**68 تست موفق، 1 تست ردشده به‌علت محدودیت محیط، 0 شکست.** دو هشدار deprecation از API سازگاری websockets دیده شد؛ شکست اجرایی نبودند.

تست ردشده، تغییر واقعی کاربر/گروه برای سنجش مجوز venv است. محیط اجرا اجازهٔ `runuser: cannot set groups` نمی‌دهد؛ آزمون جداگانهٔ مجوز فایل‌ها موفق است، ولی آزمون کامل با حساب سرویس باید روی Ubuntu انجام شود.

تست‌های رفتاری تازه شامل parser عملیات و کنترل مالکیت، SSH واقعی محلی، رمز و اثرانگشت اشتباه، پورت‌ها، نصب با سلامت مثبت/منفی، حفظ env، لغو WSS، توقف reset، شکست‌های بکاپ، مجوز سورس، اجرای JavaScript با DOM آزمایشی، ثبت handlerهای واقعی Telegram و stateها، kwargs بخش Pro، اعلان تاپیک/جایگزین مالک و قطعی/بازیابی همراه ذخیرهٔ آمار هستند.

در آزمون نصب، SSH، apt، systemd و UFW ساختگی‌اند؛ هیچ سرویس واقعی سیستم تغییر نکرده است. تولید واقعی فایل env در پوشهٔ موقت اجرا شده و newline، حفظ pin دلخواه و مجوز 0600 بررسی شده‌اند.

## آزمون‌های یکپارچهٔ تکمیلی

| آزمون | روش و نتیجه |
| --- | --- |
| SSH واقعی | سرور محلی Paramiko؛ کلید ناشناخته رد شد؛ fingerprint و رمز صحیح پذیرفته شد؛ کلید با رمز غلط ذخیره نشد؛ اتصال بعدی با کلید ثبت‌شده موفق بود |
| دیتابیس PostgreSQL | موتور PostgreSQL در PGlite با adapter آزمایشی psycopg؛ **310 دستور SQL** موفق |
| مهاجرت و مالکیت | اسکیما و Pro schema، اجرای دوبارهٔ مهاجرت، کاربران مستقل، نام تکراری، پورت صفر و agent_id/توکن/گواهی آزموده شد |
| لینک و تاریخچه | لینک یکسان دو مالک و دو اشتراک مستقل، latest status، آمار یک‌روزه، معیار کانفیگ، رتبه‌بندی و علاقه‌مندی موفق |
| نود مانیتور | انتخاب نود برای مالک و حفظ جداسازی مالک دیگر در SQL موفق |
| Xray x86_64 | آرشیو رسمی v26.3.27 دانلود و SHA-256 تطبیق داده شد؛ باینری و geodata از مسیر نصب جدید آماده شدند؛ اجرای native هسته و HTTP محلی از مسیر SOCKS موفق |
| WSS واقعی | سرور واقعی websockets روی loopback با گواهی TLS موقت؛ کلاینت خود پروژه certificate/SAN را بررسی و توکن ارسال کرد؛ get_stats و test_config روی اتصال واقعی موفق |
| سرعت اندازه‌گیری‌نشده | در تست سبک، down/up برابر null بود؛ صفر به‌عنوان اندازه‌گیری جعلی ارسال نشد |

آزمون PGlite، صحت SQL با موتور PostgreSQL را می‌سنجد؛ رفتار سرویس PostgreSQL لینوکسی، نقش‌های سیستم، شبکه و pool همزمان psycopg را جایگزین نمی‌کند. اجرای native aarch64 در این محیط انجام نشد؛ URL و هش آن در lockfile موجود است.

## بررسی‌های سورس و آرشیو

- کامپایل/parse تمام **50 فایل Python** موفق.
- تحلیل نام‌های تعریف‌نشده با `ruff check --select F821,F822,F823 .` موفق.
- بررسی نحو هر **5 اسکریپت Shell** به‌صورت مستقل موفق.
- `node --check pro_web/static/app.js` و اجرای اولیهٔ پنل در DOM آزمایشی موفق.
- `bash install.sh --check` و manifest SHA-256 برای بستهٔ نهایی و نسخهٔ دوباره استخراج‌شده موفق.
- ZIP شامل سورس، تست‌ها و راهنماها است؛ venv، cache، کلید، توکن، تنظیمات خصوصی و باینری Xray در آن قرار نمی‌گیرند.

## موارد نیازمند محیط مقصد

نصب/ارتقای کامل روی Ubuntu یا Debian دارای systemd؛ تغییر واقعی حساب سرویس؛ apt/pip و دانلود از شبکهٔ مقصد؛ UFW و فایروال ارائه‌دهنده؛ Telegram Bot API زنده؛ ورود واقعی Mini App؛ DNS/ACME؛ و اجرای طولانی با چند کاربر باید پس از نصب روی محیط مقصد تأیید شوند. هیچ اتصال یا نصب روی VPS شخصی کاربر در این بررسی انجام نشده است.

برای تکرار آزمون‌های پروژه در یک محیط جدا:

```bash
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements-web.txt pytest httpx ruff
.venv/bin/python -m pytest -q tests
.venv/bin/ruff check --select F821,F822,F823 .
for script in install.sh install_web_panel.sh scripts/*.sh; do bash -n "$script"; done
node --check pro_web/static/app.js
python3 scripts/verify_manifest.py
bash install.sh --check
```

آزمون‌های تکمیلی native Xray و PGlite در محیط بررسی اجرا شدند؛ جزو اجرای پیش‌فرض pytest نیستند و به باینری/موتور آزمایشی جدا نیاز دارند.
