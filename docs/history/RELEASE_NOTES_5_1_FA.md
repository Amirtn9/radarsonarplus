# Sonar Radar Pro 5.1 | راهنمای نصب نسخه Git-ready

این نسخه از بسته Pro 5.0 با تغییرات اساسی در نصب‌کننده آماده شده است. **زبان منوی نصب انگلیسی است** و ظاهر ترمینال با کادرهای مینیمال و نشانگرهای رنگی طراحی شده است؛ به معنی رابط گرافیکی واقعی macOS نیست.

## نصب از GitHub

ابتدا محتویات ZIP را در یک پوشه استخراج و در مخزن خودتان قرار دهید. تنها فایل‌های نمونه پیکربندی را commit کنید و هرگز توکن واقعی، کلید `secret.key`، فایل‌های `.dump`، `.env` و پسورد را در Git قرار ندهید. `.gitignore` در پروژه این موارد را کنار می‌گذارد؛ اگر قبلاً لو رفته‌اند باید رمز/توکن را تعویض و تاریخچه Git را پاک‌سازی کنید.

```bash
git clone https://github.com/YOUR_USERNAME/YOUR_REPOSITORY.git
cd YOUR_REPOSITORY
bash install.sh --check
sudo bash install.sh
```

در منو گزینه 01 را برای نصب تازه انتخاب کنید. توکن بات و شناسه عددی ادمین لازم است. نصب‌کننده PostgreSQL، محیط مجازی، سرویس bot و کلید رمزنگاری جدید تولید می‌کند. در ارتقا گزینه 02 از سورس جدید در مسیر دیگری استفاده کنید.

### پنل و گواهی

1. گزینه 03: نصب پنل تلگرام و API روی لوپ‌بک `127.0.0.1` و پورت قابل تغییر.
2. DNS دامنه را به IP سرور وصل کنید و پورت‌های 80 و 443 در فایروال/ارائه‌دهنده باز باشند.
3. گزینه 04: ثبت دامنه در nginx و درخواست گواهی Let's Encrypt. برای TLS یک آدرس ایمیل هم می‌توان تعیین کرد.
4. گزینه 10: اجرای بررسی سلامت. پنل از داخل ربات تلگرام با initData امضاشده باز می‌شود.

### دیگر گزینه‌ها

منوی Settings شامل تعویض توکن/ادمین، پورت ایجنت و پنل، محدودیت پردازش و تست، WebSocket Pool، تعداد اتصال‌های دیتابیس و روشن/خاموش کردن حالت WSS است. امکان تأیید اثرانگشت SSH سرورهای راه‌دور و ذخیره کلید شناخته‌شده، مدیریت سرویس‌ها، مشاهده لاگ، بکاپ `.dump`، بازیابی با تأیید صریح و حذف ایمن همراه با بایگانی پروژه هم اضافه شده است.

### محدودیت‌های حیاتی

- اجرای کامل روی سرور واقعی، اتصال به تلگرام، PostgreSQL عملیاتی و ایجنت‌های راه‌دور **در این محیط انجام نشده** است. قبل از سرور اصلی روی VPS آزمایشی نصب کنید.
- عقب‌گرد کد بعد از شکست نصب تضمینی برای بازگردانی خودکار تغییرات دیتابیس نیست.
- هنوز همه عملیات قدیمی به RBAC کامل مجهز نیستند و ارتباط WebSocket ایجنت‌ها با WSS سراسری نیازمند گواهی معتبر روی تک‌تک نودها است.
- پنل وب نیازی به بازکردن مستقیم پورت 8090 ندارد؛ این پورت فقط روی لوپ‌بک است.
- نصب‌کننده فقط Ubuntu و Debian با systemd را پشتیبانی می‌کند و به apt/pip اینترنتی نیاز دارد.
