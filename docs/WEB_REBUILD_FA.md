# بازسازی گزارش و پایش وب

این تغییر مسیر گزارش‌گیری، نمودار، جمع‌آوری آمار و ظاهر مشترک وب/مینی‌اپ را اصلاح می‌کند.

- گزارش فضای کاری از API واقعی خوانده می‌شود: وضعیت سرورها، آخرین CPU/RAM/Disk، کیفیت کانفیگ و رخدادها. خروجی CSV فارسی دارد و داده فضای کاری دیگر وارد گزارش نمی‌شود. سلول‌های دارای فرمول بالقوه در CSV ایمن می‌شوند.
- بازه‌های ۱، ۳، ۱۲، ۲۴ و ۴۸ ساعت در داشبورد و جزئیات سرور اضافه شده‌اند. داده کل بازه در bucketهای زمانی خوانده می‌شود؛ محدودکردن ساده به ۲۸۸ ردیف آخر حذف شده است. timestamp در محور نمودار استفاده می‌شود و شکاف داده به‌عنوان اتصال پیوسته نمایش داده نمی‌شود.
- تاریخچه تا ۳۰ روز حفظ می‌شود. مسیر قدیمی ثبت دسته‌ای دیگر تاریخچه قدیمی‌تر از یک روز را پاک نمی‌کند. داده قبلاً حذف‌شده قابل بازسازی نیست.
- داشبورد هر ۱۵ ثانیه داده ثبت‌شده را بازخوانی می‌کند. این فاصله، وعده دریافت نمونه تازه از سرور در هر ۱۵ ثانیه نیست؛ زمان آخرین سنجش در رابط دیده می‌شود.
- اجرای مستقل API نیز collector دارد: حداکثر سه سرور فعال در هر دسته، اولویت چرخشی، بررسی دسترسی مالک و استفاده از همان مسیر WSS/SSH موجود. نمونه تازه ربات دوباره درخواست نمی‌شود؛ خطای داخلی به‌جای داده ساختگی با وضعیت نامشخص ثبت می‌شود. برای نمونه‌برداری، دسترسی معتبر به Agent یا SSH لازم است.
- تم سفید و مشکی مات با زمینه شبکه‌ای، کارت‌ها، جدول گزارش و دسته‌بندی منو اضافه شد. توضیح کوتاه کنار برخی تنظیمات اعلان و اصطلاحات TLS/WSS/RTT/Webhook/Canary/Scope قرار دارد؛ بازشدن راهنما با لمس یا کیبورد ممکن است.
- دمای اندازه‌گیری‌نشده و ترافیک فاقد نمونه به‌عنوان داده واقعی نمایش داده نمی‌شوند. صفر واقعی با نبود داده متفاوت است؛ مقادیر نامعتبر نمودار حذف می‌شوند.

## محدوده

عملیات فنی موجود پنل شامل ثبت و مدیریت منابع، Agent، SSH، سرویس‌ها، کانفیگ‌ها، تیم، اعلان‌ها و مرکز سازمانی حفظ شده‌اند. این تغییر به معنی انتقال کامل **تمام** ویزاردهای ربات به مرورگر نیست؛ جریان‌های مالی/رسید، پیام همگانی و همه ابزارهای مدیریت کاربران هنوز به‌طور کامل در وب بازسازی نشده‌اند. برای این موارد دکمه نمایشی با وعده اجرای جعلی اضافه نشده است.

این نسخه داده تولیدی مشتری را در اختیار نداشت. آزمون مرورگر با دیتابیس و نمونه‌های ساختگیِ مجزا انجام شد، نه اتصال به VPS واقعی کاربر. کارکرد واقعی SSH، انتشار Agent و ارسال تلگرام همچنان به دسترسی محیط عملیاتی نیاز دارد.

## اعتبارسنجی

اجرای نهایی مجموعه پایتون: **۳۸۴ تست موفق، ۸ هشدار deprecation و ۸ subtest موفق**؛ بدون شکست یا skip.

آزمون‌های PostgreSQL شامل بازه ۱ و ۴۸ ساعت با نمونه ۳۶ ساعت قبل، جداسازی مالک، خروجی گزارش و CSV هستند. collector با probe ساختگی کنترل‌شده بررسی می‌شود. آزمون Chromium ورود، ذخیره تنظیمات، CSV، پنج بازه نمودار، پوسته روشن/تاریک و نبود overflow روی موبایل را بررسی می‌کند. داده تولیدی یا رمز مشتری در این آزمون‌ها استفاده نشده است.

برای اعمال، مخزن را به‌روز و نصب‌کننده موجود را با `--check` و سپس `--update` اجرا کنید. برای این تغییرات ظاهری و گزارش مرکزی، نصب مجدد Agent لازم نیست؛ سرور باید از قبل یک مسیر معتبر دریافت آمار داشته باشد.
