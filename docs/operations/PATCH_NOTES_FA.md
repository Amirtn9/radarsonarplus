# وصله رفع خطای نصب Agent از مسیر Relay

## فایل‌های داخل بسته
- `agent_bootstrap.py` — تنها فایل اجرایی پروژه که تغییر کرده است.
- `tests/test_agent_bootstrap_relay_venv.py` — آزمون‌های رگرسیون جدید.

## علت
در جریان نصب، نسخه Python در مرحله `probe()` با موفقیت خوانده می‌شد؛ اما اگر اتصال SSH مستقیم بسته و ارتباط از طریق Agent واسط ناپایدار بود، کد برای بار دوم نسخه Python را از راه SSH می‌خواند. شکست این درخواست دوم اشتباهاً به `VENV_PREREQUISITE_FAILED` تعبیر می‌شد.

## تغییر
- نسخه Python از خروجی probe موفق استفاده می‌شود و درخواست SSH تکراری برای کشف همان نسخه حذف شده است.
- قطع ارتباط SSH/Agent از خرابی Python و `ensurepip` تفکیک می‌شود.
- اگر مسیر ارتباطی واقعاً قطع باشد، خطای `SSH_TRANSPORT_UNAVAILABLE` نمایش داده می‌شود؛ نصب‌کننده دیگر آن را به‌عنوان خرابی Python گزارش نمی‌کند.
- خطاهای مسیر ارتباطی در بررسی اولیه، پیش‌نیازها و venv نیز به‌درستی تفکیک می‌شوند.

## نصب
فایل `agent_bootstrap.py` را در ریشه پروژه با نسخه داخل بسته جایگزین کنید. پوشه `tests` فقط برای آزمون است و برای اجرای برنامه لازم نیست.
