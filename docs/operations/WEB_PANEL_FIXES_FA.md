# اصلاحات پنل وب SONAR RADAR PRO 6.9

این بسته بر اساس سورس 6.9 ارسالی تهیه شده است.

## تغییرات

1. **بارگذاری SDK تلگرام**
   - وابستگی مستقیم و مسدودکننده از زنجیره `defer` صفحه حذف شد.
   - SDK به‌صورت `async` و با مهلت انتظار ۱٫۸ ثانیه بارگذاری می‌شود.
   - در صورت در دسترس نبودن CDN، اجرای پنل متوقف نمی‌شود و مسیر ورود وب نمایش داده می‌شود.
   - اگر SDK با تأخیر برسد، راه‌اندازی احراز هویت دوباره امتحان می‌شود.

2. **پایداری Workerها**
   - Uvicorn در سرویس وب با یک Process اجرا می‌شود؛ چون Workerهای پس‌زمینه فعلاً داخل رویداد Startup همان Process ساخته می‌شوند.
   - این کار از اجرای تکراری Workerها و پردازش موازی ناخواسته جلوگیری می‌کند.
   - هندل‌کردن درخواست‌های هم‌زمان HTTP همچنان با مدل async و Thread Pool برنامه انجام می‌شود.
   - برای افزایش تعداد Processها در آینده، Workerهای پس‌زمینه باید ابتدا به سرویس مستقل منتقل شوند.

3. **سلامت واقعی سرویس**
   - نصب‌کننده علاوه بر `/healthz`، مسیر `/readyz` را هم بررسی می‌کند.
   - بررسی محلی و بررسی HTTPS عمومی تا آماده‌شدن دیتابیس و Schemaهای اصلی صبر می‌کنند.

4. **فهرست منابع**
   - API منابع پارامتر `per_page` با سقف ۵۰ رکورد را می‌پذیرد.
   - انتخاب‌گر سرورها به‌جای سقف ثابت ۶۰ مورد، صفحه‌ها را تا ۵۰۰۰ رکورد دریافت می‌کند و در صورت عبور از سقف، خطای روشن نمایش می‌دهد.

5. **Nginx**
   - نمونه Reverse Proxy اکنون مسیر WebSocket ترمینال SSH را با Upgrade صحیح دارد.
   - مسیر Bundle عیب‌یابی Timeout جداگانه و طولانی دارد.
   - هدرهای Forwarded و نسخه HTTP پروکسی کامل شده‌اند.

## بررسی‌های انجام‌شده

- بررسی نحوی Python برای `pro_portal.py`: موفق
- بررسی نحوی Bash برای `install.sh`: موفق
- `node --check` برای تمام فایل‌های JavaScript پنل: موفق
- آزمون‌های مرتبط و رگرسیون: ۷۲ موفق، ۷ مورد Skip، بدون شکست
- بررسی نحوی نمونه Nginx با `nginx -t`: موفق

این بررسی‌ها روی سورس محلی انجام شده‌اند؛ اجرای زنده روی VPS و بررسی مرورگر/دامنه واقعی انجام نشده است.

## روش اعمال روی VPS

1. از مسیر فعلی `/opt/radar-sonar` یک بکاپ بگیر.
2. فایل‌های بسته کامل را روی همان مسیر جایگزین کن؛ دیتابیس و پوشه Runtime را حذف نکن.
3. سرویس پنل را با دستور زیر بازسازی و راه‌اندازی مجدد کن:

```bash
sudo bash /opt/radar-sonar/install.sh --panel
```

این دستور سرویس وب را بازسازی و Restart می‌کند؛ دستور Clean Install نیست و نباید دیتابیس را Reset کند.

4. بعد از اجرا، این دو مسیر را بررسی کن:

```bash
curl -i http://127.0.0.1:8090/healthz
curl -i http://127.0.0.1:8090/readyz
```

اگر پورت وب در نصب تو 8090 نیست، پورت تنظیم‌شده در `SONAR_WEB_PORT` را جایگزین کن.
