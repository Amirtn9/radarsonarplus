# 🦇 راهنمای نصب مجدد و بازیابی Sonar Radar Pro 5.3.0

برای ارتقای بدون حذف داده، ابتدا [راهنمای ارتقا به 5.3.0](../UPGRADE_NOTES_FA.md) را بخوانید. فایل حالت و کلید نسخهٔ جدید در `/var/lib/sonar-radar` نگهداری می‌شود.

این سند مخصوص سروری است که نصب قبلی رادار سونار روی آن ناقص مانده است.

## خطای قبلی چه بود؟

در گزارش سرور Ubuntu 24.04 عبارت `status=203/EXEC` و `Permission denied` هنگام اجرای `/opt/radar-sonar/venv/bin/python` ثبت شده بود. در نسخه قبل، virtualenv با `umask 077` ساخته می‌شد و کاربر systemd ممکن بود اجازه عبور از پوشه‌های داخلی آن را نداشته باشد. پیام `StartLimitIntervalSec` نیز به قرارگیری گزینه در بخش نادرست فایل سرویس مربوط بود. هشدار `sudo: unable to resolve host ubuntu` ایراد مستقلی در تنظیمات hostname است.

## انتشار روی GitHub

محتویات ZIP را در ریشه شاخه `main` مخزن `Amirtn9/radarsonarplus` قرار بدهید. فقط پس از انتشار نسخه جدید از آدرس زیر نصب کنید.

```bash
wget https://raw.githubusercontent.com/Amirtn9/radarsonarplus/main/install.sh
chmod +x install.sh
sudo ./install.sh
```

گزینه `01` نصب کامل و گزینه `14` پاک‌سازی کاملِ تأییدشده به همراه نصب مجدد است.

## قبل از پاک‌سازی

```bash
sudo bash install.sh --inventory
sudo bash install.sh --doctor
sudo bash install.sh --logs errors --lines 100
```

در صورت شناسایی نصب قبلی، اینستالر دو حالت پیشنهاد می‌دهد: ارتقا با حفظ داده یا آرشیو، حذف و نصب تمیز. پاک‌سازی نیازمند تایپ دقیق عبارت `DELETE SONAR DATA` است. خود PostgreSQL و سایر دیتابیس‌ها حذف نمی‌شوند. بکاپ‌ها در `/var/backups/sonar-radar` ذخیره می‌شوند و در عملیات پاک‌سازی به‌طور پیش‌فرض حفظ می‌شوند.

**احتیاط:** اگر در حین نصب تمیز برق/اینترنت قطع شود یا تست Bot شکست بخورد، بایگانی داده و کلید رمزنگاری باید با بررسی انسانی بازگردانده شود. یکسان بودن نسخه کد با نسخه schema دیتابیس را پس از بازیابی بررسی کنید. حذف داده عملیاتی برگشت‌ناپذیر است مگر نسخه پشتیبان سالم و کلید رمزنگاری را داشته باشید.

## راه‌حل ریشه‌ای دسترسی‌ها

- نصب پیش از فعال‌سازی سرویس، venv و تمام وابستگی‌های Bot و Mini App را آماده می‌کند.
- خواندن/اجرای فایل‌های عمومی Python برای کاربر `sonar-bot` مجاز می‌شود، نه نوشتن در کد.
- کلید رمزنگاری و فایل تنظیمات همچنان 0600 می‌مانند.
- یک اجرای آزمایشی با `runuser -u sonar-bot` انجام می‌شود.
- `StartLimitIntervalSec` و `StartLimitBurst` در بخش `[Unit]` قرار می‌گیرند.
- لاگ کامل خطای استارت داخل خروجی عیب‌یابی چاپ می‌شود.

## نصب روی محیط واقعی هنوز بررسی می‌خواهد

تست‌های موجود از نوع آفلاین هستند. برای تأیید نهایی باید سرویس روی Ubuntu خود شما نصب شود، `sudo bash install.sh --doctor` وضعیت سالم گزارش دهد، `/start` ربات و endpoint سلامت Mini App را تست کنید، سپس WSS و SSL را بررسی کنید.
