# راهنمای نصب و بازیابی نسخه ۶

راهنمای کامل [نصب و ارتقا](../UPGRADE_NOTES_FA.md) و دستورات [README](../README.md) را ببینید.

برای نصب آزمایشی: `bash install.sh --check` سپس `sudo bash install.sh` و گزینه `01`.

برای گزارش خطا بدون نیاز به اجرای ربات: `sudo bash install.sh --support`.

برای تعمیر یا بازیابی: از منوی نصب `10`، `13` و `09` استفاده کنید. **نصب پاک (14) داده را پس از بکاپ و تأیید صریح حذف می‌کند.**
