# نقشه پروژه Sonar Radar Pro

## مسیرهای اصلی

- `bot.py` و `v6_ui.py`: نقطه ورود ربات و رابط‌های مدیریتی تلگرام.
- `pro_portal.py`: API پنل وب و مینی‌اپ؛ احراز هویت، نقش‌ها، وضعیت و عملیات وب.
- `pro_web/index.html`: پوسته پنل؛ داشبورد صفحه آغازین است.
- `pro_web/static/app.js`: ناوبری، داشبورد، مدیریت منابع و دریافت گزارش‌ها.
- `pro_web/static/web_ops.js`: عملیات سرور، بررسی SSH و افزودن مرحله‌ای.
- `pro_web/static/next.js`: مدیریت Agentها، صف نصب و عملیات تکمیلی.
- `pro_web/static/balancer.js`: استخر Agentهای چندمنطقه‌ای، اولویت و سیاست مسیر.
- `core.py`, `ssh_support.py`, `server_onboarding.py`: ارتباط SSH، تأیید اثرانگشت و افزودن مرحله‌ای سرور.
- `ssh_relay.py`, `monitor_fleet.py`: مسیر جایگزین SSH، استخر Agent، اولویت، سلامت و affinity.
- `agent_deploy.py`, `agent_bootstrap.py`, `agent_xray_bridge.py`: نصب/تعمیر Agent، پیش‌نیازها و انتقال بسته‌ها.
- `database.py` و ماژول‌های `*_api.py`: دیتابیس و APIهای عملیاتی.
- `diagnostics.py` و `scripts/sonar-diagnostic-read.sh`: خروجی کامل لاگ، snapshot امن و خواندن محدودشده journal.
- `scripts/`: نصب، تعمیر، خواندن لاگ و ابزارهای استقرار.
- `tests/`: آزمون‌های خودکار.
- `docs/operations/`: راهنمای عملیاتی نسخه جاری.
- `docs/history/` و `docs/archive/`: مستندات نسخه‌های قدیمی و بایگانی‌شده.

## جریان ارتباط

```text
پنل وب / مینی‌اپ ─┐
                  ├── API مشترک ── PostgreSQL
ربات تلگرام ──────┘

عملیات SSH:
سرور مرکزی (مسیر اول) ──> مقصد
       │ در خطای شبکه
       ├──> Agent با اولویت بالاتر ──> مقصد
       ├──> Agent بعدی ──────────────> مقصد
       └──> Agent بعدی ──────────────> مقصد

تأیید SSH از کنترل‌کننده انجام می‌شود؛ Agent صرفاً جریان رمزگذاری‌شده را حمل می‌کند.
```

## کنترل اندازه پوشه‌ها

در نسخه بسته‌بندی‌شده، هیچ پوشه‌ای بیش از ۹۰ فایل مستقیم ندارد. کش‌های اجرا (`__pycache__`, `.pytest_cache`) جزو فایل‌های تحویلی نیستند. مستندات تاریخی حفظ شده‌اند و فایل اجرایی حذف نشده است مگر کش/فایل کامپایل‌شده قابل‌بازتولید.
