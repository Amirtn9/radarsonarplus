# راهنمای نصب‌کننده و حذف کامل Sonar Radar Pro

## رابط نصب‌کننده

با اجرای `sudo bash install.sh`، در صورت نصب بودن `whiptail` منوی تعاملی تمام‌صفحه باز می‌شود. اگر `whiptail` در دسترس نباشد، منوی رنگی متنی استفاده می‌شود. نصب وابستگی‌ها، `whiptail` را برای اجراهای بعدی اضافه می‌کند.

## تفاوت عملیات حذف

- `--uninstall`: برنامه را آرشیو می‌کند و دیتابیس، کلیدها و Backupها را نگه می‌دارد.
- `--clean-install`: از داده‌های موجود Backup تأییدشده می‌گیرد، اجزای Sonar را پاک می‌کند و بلافاصله نصب تازه را آغاز می‌کند.
- `--purge`: حذف کامل و غیرقابل‌بازگشت اطلاعات محلی Sonar است و پس از پایان از نصب‌کننده خارج می‌شود. هیچ نصب مجددی اجرا نمی‌شود.

برای حذف کامل:

```bash
sudo bash install.sh --purge
```

این عملیات پس از نمایش فهرست منابع، تأیید اولیه و وارد کردن دقیق عبارت `DELETE ALL SONAR DATA` اجرا می‌شود. هیچ Backupای نگه داشته نمی‌شود؛ بنابراین پیش از آن، در صورت نیاز، Backup مستقل بگیرید.

## محدوده حذف

در نصب استاندارد، موارد زیر حذف می‌شوند:

- `/opt/radar-sonar` و محیط مجازی Python
- `/var/lib/sonar-radar` شامل state، کلید رمزنگاری، SSH known_hosts و Backupهای محلی
- دیتابیس محلی PostgreSQL با نام پیکربندی‌شده (پیش‌فرض `sonar_ultra_pro`) و Role اختصاصی (پیش‌فرض `sonar_user`)
- `/etc/sonar-bot.env` و Unitهای `sonar-bot` و `sonar-web` و overrideهای اختصاصی آن‌ها
- تنظیم Nginx مختص Sonar در `sites-available` و symlink متناظر در `sites-enabled`
- `/var/backups/sonar-radar`، `/var/log/sonar` و `/var/log/sonar-install.log`
- helper و sudoers rule اختصاصی Diagnostics
- حساب سرویس `sonar-bot` فقط اگر Home آن دقیقاً `/opt/radar-sonar` باشد
- پوشه checkout جاری فقط اگر در `/root` و با نام شناخته‌شده پروژه باشد و اپراتور جداگانه حذف آن را تأیید کند

## مواردی که عمداً حذف نمی‌شوند

برای جلوگیری از آسیب به سرویس‌های دیگر، عملیات حذف، بسته‌های PostgreSQL، Nginx، Python، SSH، Certbot یا سایر بسته‌های سیستم را Uninstall نمی‌کند؛ دیتابیس‌های دیگر PostgreSQL را دست نمی‌زند؛ تنظیمات Nginx دیگر سایت‌ها را تغییر نمی‌دهد؛ Agentهای نصب‌شده روی سرورهای راه‌دور و گواهی‌های TLS را حذف نمی‌کند؛ و Journal مشترک systemd را پاک نمی‌کند. اگر دیتابیس راه‌دور تنظیم شده باشد، Purge قبل از حذف هر داده‌ای متوقف می‌شود.

اگر Role دیتابیس در دیتابیس دیگری هم استفاده شده باشد، برای حفاظت از آن داده‌ها Role نگه داشته می‌شود و در خروجی اعلام می‌شود.

## تشخیص نسخه سورس

`--check` اکنون نسخه، مسیر checkout، Revision، تعداد فایل‌های Python و اعتبار Manifest را نشان می‌دهد. اگر تعداد فایل‌ها با نسخه مورد انتظار متفاوت باشد، احتمالاً از checkout قدیمی یا ترکیبی از چند نسخه استفاده می‌شود. از ZIP اصلاح‌شده در مسیر جداگانه استخراج و همان فایل `install.sh` را اجرا کنید؛ اجرای اسکریپت قدیمی از `/opt/radar-sonar` یا یک clone قدیمی باعث استفاده از نصب‌کننده قدیمی می‌شود.
