# نتیجه آزمون و بازبینی پچ وب/Agent

**تاریخ بررسی: ۱۴۰۵/۰۷/۲۹ (۲۱ اکتبر ۲۰۲۶)**  
**پایه کد:** Sonar Radar Pro 6.6.0-rc3

## آزمون‌های آفلاین

| بررسی | نتیجه |
|---|---|
| آزمون‌های جدید برای direct-first، fallback Agent، اثرانگشت و مالکیت | ۷ از ۷ موفق |
| آزمون‌های انتخابی web/fleet/installer/portal | موفق در زیرمجموعه‌های قابل اجرا |
| اجرای کل `pytest -q tests` روی محیط در دسترس | **۱۹۱ موفق، ۴ ناموفق، ۲ خطای راه‌اندازی تست** |
| علت چهار شکست و دو خطای باقی‌مانده | فقدان وابستگی‌های `paramiko` و `python-telegram-bot` در محیط آزمون |
| اتصال واقعی SSH/TLS/WSS به VPS ایران/خارج | اجرا نشده؛ سرور و مدارک دسترسی ارائه نشده است |
| PostgreSQL واقعی با دیتابیس تولیدی | اجرا نشده؛ به دیتابیس مشتری اتصال نداریم |
| Telegram واقعی، Mini App و مرورگر HTTPS زنده | اجرا نشده؛ محیط استیجینگ/توکن/دامنه در اختیار نیست |
| استقرار و ارتقای واقعی install.sh | اجرا نشده؛ نصب روی سرور کاربر انجام نشده است |

**توجه:** ۱۹۱ آزمون موفق به معنی آمادگی قطعی برای تولید یا رفع صددرصدی خطای لاگ نیست. اجرای مجموعه کامل پس از نصب `requirements-web.txt` و `requirements-dev.txt` روی محیط سازگار ضروری است.

## آزمون‌های ضروری بعد از استقرار آزمایشی

1. تأیید اتصال مستقیم سرور مرکزی در SSH و ثبت کلید مستقل.
2. قطع ارتباط مرکزی و تست Agent فعال با TLS پین‌شده، توکن، allowlist پورت و SSH صحیح.
3. بررسی ردشدن fingerprint غلط و رمز SSH غلط بدون ثبت سرور.
4. نصب Agent روی پورت 8080 و پورت سفارشی با تداخل و بدون تداخل.
5. ثبت، حذف، تغییر پوشه و نصب از پنل وب و مشاهدهٔ بی‌درنگ داده از ربات و برعکس.
6. تست همزمانی نصب، ریستارت سرویس وب حین نصب، کارهای منقطع و ثبت علت خطا.
7. آزمایش بازیابی بکاپ PostgreSQL، کلید رمزنگاری و known_hosts پیش از هر ارتقا.
8. بررسی مجدد لاگ‌های Agent شماره ۴ و وضعیت WSS/TLS پس از استقرار.

## قابلیت‌های توسعه‌نیافته

این بسته اصلاح و توسعه **بخش سرور/Agent وب** است؛ بازنویسی کامل همه منوهای ربات، مدیریت پیشرفته کانفیگ، ترمینال تعاملی از وب، تمام وظایف مدیریتی و پرداخت در پنل وب تکمیل نشده‌اند. قابلیت‌های موجود ربات حفظ شده‌اند؛ در پنل وب امکاناتی که واقعاً API دارند نمایش داده می‌شود.
