# مقایسه منطق تست کانفیگ و بررسی نسخه Agent

این بررسی روی کد دریافت‌شده در ۱۵ نوامبر ۲۰۲۶ انجام شد، نه تعداد ستاره‌ها، تصاویر پیوست یا امکانات ادعاشده در README. پروژه‌های مرجع اجرا نشدند؛ تست اجرایی روی پیاده‌سازی خود Sonar و هسته‌های Xray قفل‌شده انجام شده است. کد خارجی به پروژه کپی نشده است.

## مشکل‌های تأییدشده و اصلاح

۱. میانگین تأخیر به نمونه پرت حساس بود. اکنون `ping` میانه نمونه‌های موفق یک مقصد است و پاسخ `latency_statistic=median` دارد. `jitter` همچنان دامنه بیشینه منهای کمینه همان مقصد است؛ این مقدار جیتر استاندارد بسته‌های UDP نیست. تأخیر نیز زمان کل درخواست HTTP است، نه ICMP یا صرفاً TCP handshake.

۲. شکست‌های میان نمونه‌های موفق از امتیاز حذف می‌شدند. اکنون `attempt_count`، `sample_count` و `success_rate` ثبت می‌شوند. امتیاز پایه در نسبت موفقیت ضرب می‌شود و کمتر از سه نمونه موفق با ضریب تعداد نمونه/۳ محدود می‌شود. این اصلاح در Agent، کنترلر و ثبت نتیجه دوره‌ای یکسان اعمال شده است. Agentهای قدیمی فاقد این اطلاعات، رفتار امتیاز قبلی را حفظ می‌کنند تا ارتقا یابند.

۳. اولین شکست باعث کنار گذاشتن مقصد می‌شد؛ حتی یک خطای گذرا فرصت آزمون مجدد نداشت. هر مقصد حداکثر دو شکست در همان دور تحمل می‌کند؛ پس از آن مقصد مستقل بعدی امتحان می‌شود. سقف هشت تلاش و بودجه ۳۶ ثانیه‌ای حفظ می‌شود. شکست سایت اول، نسبت موفقیت سایت دوم را خراب نمی‌کند و نمونه‌های دو مقصد برای جیتر مخلوط نمی‌شوند.

۴. یک نمونه موفق می‌توانست جیتر صفر و امتیاز عالی بدهد. اکنون اطلاعات اطمینان `limited` و پایداری `insufficient_samples` یا `unstable` همراه امتیاز محدود برمی‌گردد. موفقیت حداقلی همچنان نشانه عبور ترافیک است؛ به معنی پایداری نیست. نتیجه Unknown نیز سلامت قبلی را به Fail تبدیل نمی‌کند.

۵. تنظیمات شخصی curl می‌توانستند تنظیمات آزمون را تغییر دهند. `--disable` در اولین آرگومان curl قرار گرفت تا `.curlrc` خوانده نشود. SOCKS5h، غیرفعال‌کردن NO_PROXY و اعتبارسنجی TLS مقصد حفظ شدند. دانلود اختیاری نیز سقف اندازه دارد و شکست آن سلامت اتصال را عوض نمی‌کند.

## بررسی نسخه Agentها

- پنل وب ← بالانسر مسیرها ← «بررسی نسخه Agentها و Xray»: بررسی همه سرورهای فهرست، در دسته‌های ۱۲تایی؛ API هر درخواست حداکثر ۳۰ شناسه می‌پذیرد و شش ارتباط هم‌زمان دارد.
- ربات ← مدیریت Agentها ← انتخاب Agentها ← «بررسی نسخه Agentها»: حداکثر ۱۲ انتخاب اول در هر بار.
- هر دو مسیر مخصوص مدیر اصلی هستند و از WSS، TLS و توکن موجود استفاده می‌کنند. اتصال SSH یا اجرای دستور دلخواه برای بررسی نسخه لازم نیست.
- نسخه Agent، پروتکل و اثرانگشت SHA-256 مجموعه هفت فایل مرتبط بررسی می‌شود. JSON فایل lock پیش از هش استاندارد می‌شود تا فاصله‌گذاری باعث اختلاف کاذب نشود.
- Agent اثرانگشت را هنگام شروع فرایند ثبت می‌کند؛ تعویض فایل‌ها بدون راه‌اندازی مجدد نباید فرایند قدیمی را مطابق بیلد جدید نشان دهد. این شناسه، تأیید رمزنگاری‌شده حافظه فرایند یا جایگزین امضای انتشار نیست.
- نتیجه‌ها: «مطابق نسخه مرکزی»، «بیلد/نسخه متفاوت»، «پروتکل ناسازگار»، «نامشخص». تفاوت نسخه لزوماً قدیمی بودن نیست؛ ممکن است نسخه جدیدتر یا سفارشی باشد. Agentهای قدیمی بدون متادیتا نامشخص می‌مانند.
- نسخه Xray و Xray سازگاری از اجرای محدود `xray version` خوانده می‌شود. نتیجه با توجه به مسیر، زمان تغییر و اندازه فایل کش می‌شود. اطلاعات ثبت‌شده نصب جدا حفظ می‌شوند و جای نسخه واقعی را نمی‌گیرند. نسخه برابر، به‌تنهایی اصالت باینری را تضمین نمی‌کند.
- نصب و بازگردانی Agent فایل جدید `agent_inventory.py` را نیز منتقل و مدیریت می‌کنند. این قابلیت هیچ Agentی را خودکار آپدیت نمی‌کند.

## محدودیت‌های روشن

مسیر عملیاتی فعلی بر Xray و پروتکل‌های VLESS، VMess، Trojan و Shadowsocks متکی است. Hysteria2 و TUIC در این تغییر اضافه نشده‌اند؛ پشتیبانی واقعی آن‌ها نیازمند هسته مناسب، قفل نسخه، توزیع امن، تبدیل کانفیگ و تست عبور ترافیک UDP است. صرف پذیرش لینک یا اعتبارسنجی JSON پشتیبانی عملیاتی محسوب نمی‌شود.

در پروفایل کامل، قوانین routing کاربر حفظ می‌شوند و نتیجه `measurement_scope=profile_route` دارد؛ در صورت direct بودن مسیر مقصد تست، نباید آن را اثبات عبور از یک outbound خاص دانست. سرعت اختیاری، نرخ موفقیت همین دور و جیتر HTTP نیز جای بررسی پایداری چندساعته یا اندازه‌گیری از داخل ایران را نمی‌گیرند.

این تغییرات محلی هستند؛ اتصال به VPS و استقرار روی سرور واقعی تأیید نشده است.

## نتیجه اعتبارسنجی

- اجرای نهایی کامل: ۶۷۸ تست موفق، ۸ زیرتست موفق و بدون تست ردشده یا نادیده‌گرفته‌شده؛ پنج هشدار موجود ثبت شده‌اند.
- هر ۹ مجموعه مرورگر موفق؛ سناریوی جدید، نمایش Agent مطابق بیلد و Agent قطع‌شده به‌صورت نامشخص را کنترل می‌کند.
- تست مستقل مرورگر برای نمایش میانه، تعداد موفق/کل، ناپایداری، کمبود نمونه و امتیاز موفق بود.
- مجموعه تست واقعی Xray شامل ۲۸ حالت عبور ترافیک محلی است: انتقال‌های TCP، WS، XHTTP، HTTPUpgrade و gRPC، حالت‌های TLS و routing، هسته سازگاری، Trojan با رمز دارای دونقطه، Shadowsocks و Reality/Vision. این نتیجه دسترسی از شبکه واقعی ایران را تأیید نمی‌کند.
- بررسی یکپارچگی فایل‌ها، تطابق نسخه انتشار، نقشه پروژه، خطاهای نام تعریف‌نشده Python و نحو JavaScript موفق بودند.
- تلاش مجدد اتصال TCP به پورت ۲۲ سرور معرفی‌شده با `ConnectionRefusedError` مواجه شد؛ هیچ نصب، تغییر تنظیمات یا راه‌اندازی مجدد روی VPS انجام نشد.
