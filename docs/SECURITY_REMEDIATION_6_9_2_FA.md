## موارد الزامی پیش از Production

1. اجرای CI روی GitHub و رفع هر شکست ناشی از وابستگی‌های واقعی.
2. اجرای دو پروسس Bot/Web هم‌زمان روی PostgreSQL staging و بررسی ledger/قفل.
3. آزمون SSH key واقعی با کلید رمزدار و بدون passphrase روی یک سرور آزمایشی.
4. ساخت Backup و بازیابی آن روی دیتابیس جداگانه، همراه کلید و تنظیمات متناظر.
5. تعریف و نگهداری امن کلید امضای انتشار یا استفاده از release commit امضاشده.
