RadarSonarPlus 6.9 — Full source repair package

This ZIP contains the complete project source plus the installer fixes identified
during the 2026-11-03 audit. Extract it to a separate directory; do not extract
over /opt/radar-sonar while a service is running.

Changes in this package:
- Restores .gitattributes and .gitignore and includes both in the integrity manifest.
- Fixes the web systemd unit so ExecStart is a real directive, not part of a comment.
- Grants the web service write access to its private runtime directory for scheduled backups.
- Makes systemd-analyze verification of the web unit a hard pre-install check.

Safe verification and installation:
  sudo bash install.sh --check
  sudo bash install.sh --install

If an earlier installation rolled back its application code but retained PostgreSQL
and runtime state, choose the Resume / Preserve existing database and runtime data
option. Do not choose Clean Reset unless you intentionally want to delete Sonar data.

The installer may apply PostgreSQL schema migrations. Database migrations are not
automatically reversed by code rollback. Keep a verified backup before upgrading.
