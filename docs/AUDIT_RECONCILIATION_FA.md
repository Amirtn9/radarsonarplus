# تطبیق گزارش ممیزی ارسالی با سورس فعلی

تاریخ: ۱۵ نوامبر ۲۰۲۶. مبنا: checkout موجود، اصلاحات همین گفت‌وگو و خواندن مستقیم ref گیت. در زمان بررسی، HEAD محلی و `origin/main` هر دو `2860b4a4fb0a6ba58fa1a2a8d6905aeb77f24460` بودند. تغییرات محل کار هنوز به GitHub ارسال یا روی VPS مستقر نشده‌اند. فایل گزارش ارسالی ورودی بررسی است و ادعاهای آن بدون تطبیق پذیرفته نشده‌اند.

## جزئیات سیاست ثبت‌نام

نتیجه اعتبارسنجی نهایی: **۶۶۸ آزمون Python و ۸ زیرآزمون موفق، بدون شکست یا skip**؛ ۵ هشدار runner ثبت شد. هر **۹ مجموعه مرورگر** موفق بودند، شامل cold-load، single-flight، شکست و retry فایل ماژول، ورود مستقیم، جلوگیری از بازنویسی صفحه جدید با پاسخ بارگذاری قدیمی و ۴۶۴ بررسی واکنش‌گرایی/پوسته. Release labels، نقشه ساختار، Manifest، Ruff و نصب frozen npm نیز موفق بودند. پنج سناریوی ثبت‌نام پیش از اصلاح شکست خوردند و پس از اصلاح موفق شدند.

اگر trial رایگان فعال و منتشرشده باشد، حساب جدید همان trial را می‌گیرد. اگر نباشد، رکوردی با `plan_id=NULL`، نام «در انتظار انتخاب پلن»، وضعیت suspended، تاریخ منقضی و ظرفیت/مصرف صفر ساخته می‌شود. ربات علت را توضیح می‌دهد و مسیر خرید را نشان می‌دهد. خرید موفق همین حساب را به پلن فعال ارتقا می‌دهد. ساخت حساب با خریدن اشتراک یکی نیست و نبود پیشنهاد رایگان، مجوز فنی ضمنی ایجاد نمی‌کند.

قفل شناسه کاربر پیش از بررسی وجود حساب گرفته می‌شود. ایجاد user و subscription یک commit دارند؛ failure میانی رکورد نیمه‌کاره نمی‌گذارد. ثبت‌نام مجدد، پلن، زمان و override موجود را بازنویسی نمی‌کند. حساب‌های Legacy با داده قبلی عمداً حفظ شده‌اند؛ این تغییر مهاجرت دسته‌جمعی حساب‌های فاقد Subscription نیست.

## کنترل انتشار و ساختار

```bash
python scripts/check_release.py
python scripts/update_project_structure.py
python scripts/update_project_structure.py --check
python scripts/verify_manifest.py
```

حالت `--check` نقشه را تغییر نمی‌دهد و وجود فایل جدید/حذف‌شده را تشخیص می‌دهد. کنترل بودجه مستقیم دایرکتوری (`--check-limits`) مستقل است و برای ساختار فعلی flat خطا می‌دهد؛ برای عبور از آن، هیچ ماژولی بدون بازبینی سازگاری جابه‌جا نشد و سقف به عدد دلخواه افزایش نیافت.

آزمون‌های محلی موفق یا تنظیم workflow به معنی اجرای موفق GitHub Actions روی تغییرات منتشرنشده نیستند. همچنین تأیید مرورگر Chromium در fixture محلی، جایگزین آزمایش Mini App روی همه کلاینت‌های واقعی تلگرام، DNS عمومی، SSH/WSS خارجی، نصب VPS و بازیابی عملیاتی نیست.
