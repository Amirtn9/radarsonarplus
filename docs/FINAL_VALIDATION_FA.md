# نتیجه بازبینی و اعتبارسنجی تکمیلی

تاریخ آخرین اجرای محلی: ۱۵ نوامبر ۲۰۲۶. نسخه برنامه مطابق `VERSION` همچنان `6.9.10` است؛ برای تشخیص تفاوت کد Agentها از اثرانگشت بیلد نیز استفاده می‌شود. گزارش‌های دیگر این پوشه، وضعیت و نتیجه هر مرحله از بررسی را در زمان همان مرحله ثبت می‌کنند.

## اصلاحات اصلی

- تست واقعی کانفیگ با SOCKS5h و Xray، میانه تأخیر، آزمون مجدد محدود، تفکیک مقصدهای تست، ثبت نسبت موفقیت و محدودکردن امتیاز نمونه‌های ناکافی. خطای محیط یا سایت سنجش به‌تنهایی کانفیگ را قطع‌شده اعلام نمی‌کند.
- بررسی نسخه Agent، پروتکل، اثرانگشت مجموعه فایل‌ها و نسخه واقعی هر دو هسته Xray در ربات و پنل. اطلاعات ناقص و نود غیرقابل‌دسترسی به‌صورت «نامشخص» نمایش داده می‌شوند.
- ثبت‌نام و تخصیص اشتراک در یک تراکنش؛ در نبود پلن رایگان، حساب جدید برای خرید و مشاهده باز می‌ماند و ظرفیت عملیاتی صفر دارد. تکرار تخصیص اشتراک، پلن پرداخت‌شده و ظرفیت اختصاصی را بازنویسی نمی‌کند.
- اتصال توکن API به فضای کاری صادرکننده و جلوگیری از افزایش مجوز توکن فرزند نسبت به والد.
- تکمیل تعریف اولیه `sonar_web_sessions` و افزودن Migration شماره ۲۰، `web_session_columns`، برای ترمیم ستون‌های `elevated_at` و `last_seen_at` در نصب‌های قبلی. ترمیم، Session قبلی را خودکار elevated نمی‌کند. نصب کامل قبلاً از طریق Migration شماره ۱۸ این ستون‌ها را دریافت می‌کرد.
- شمارش منابع مستقل از OFFSET با همان فیلترها و snapshot دیتابیس؛ صفحه خالی خارج از محدوده، تعداد کل را صفر نمی‌کند. رابط کاربری به آخرین صفحه معتبر برمی‌گردد و سابقه ناوبری را اصلاح می‌کند.
- اصلاح فرم‌های مدیریت اشتراک، ظرفیت اختصاصی، کیف پول و مقصد پرداخت؛ بارگذاری ماژول‌های اختیاری هنگام استفاده، حفظ راهنمای تنظیمات و بازیابی بارگذاری ناموفق.
- انتخاب بسته ایموجی سفارشی توسط مدیر اصلی Premium، بررسی پذیرش تلگرام، ذخیره تنظیم و بازگشت به ایموجی معمولی در صورت رد مجوز.
- افزودن مجوز MIT مطابق انتخاب مالک، کنترل تطابق برچسب نسخه و نقشه خودکار پروژه در CI.

## نتیجه اجرای آزمون‌ها

تمام محیط‌های Python با فایل hash-lock متناظر CI نصب و بررسی شدند. پایگاه داده محلی PostgreSQL 17 و مرورگر Chromium بود؛ پیکربندی GitHub Actions از PostgreSQL 16 استفاده می‌کند.

| محیط | تست موفق | زیرتست موفق | ناموفق / خطا / نادیده‌گرفته‌شده |
| --- | ---: | ---: | --- |
| Python 3.10.22 | ۶۸۳ | ۸ | صفر |
| Python 3.11.18 | ۶۸۳ | ۸ | صفر |
| Python 3.12.14 | ۶۸۳ | ۸ | صفر |
| مرورگر | هر ۹ مجموعه | — | صفر |

پنج هشدار در هر اجرای pytest ثبت شد؛ هیچ تستی شکست نخورد. پوشش شامل نصب روی دیتابیس کاملاً خالی، ارتقای دیتابیس قبلی، تراکنش‌های مالی و سهمیه هم‌زمان، احراز هویت و مجوز فضای کاری، شمارش فیلترشده در صفحات خالی، ناوبری مرورگر، ایموجی و مسیر واقعی WSS است. ۲۸ حالت عبور ترافیک محلی با هسته‌های Xray قفل‌شده نیز اجرا شد.

کامپایل Python در هر سه نسخه، سازگاری وابستگی‌ها، خطاهای نام تعریف‌نشده، نحو Shell و JavaScript، preflight نصب، برچسب نسخه، نقشه پروژه و manifest فایل‌ها بررسی شدند. اسکن فایل‌های تغییرکرده نیز الگویی از توکن تلگرام/GitHub، کلید AWS یا کلید خصوصی پیدا نکرد؛ این اسکن جای بررسی کامل امنیتی را نمی‌گیرد.

## محدوده نتیجه

این نتایج تضمین نبود هرگونه باگ در تمام شرایط نیستند. تست محلی، اتصال از شبکه واقعی ایران، نصب روی VPS معرفی‌شده و مجوز واقعی Bot API برای بسته ایموجی را تأیید نمی‌کند. مسیر SSH سرور معرفی‌شده در بررسی قبلی اتصال را رد می‌کرد.

Hysteria2 و TUIC در مسیر فعلی تست، پشتیبانی عملیاتی ندارند. نتیجه مسیر یک پروفایل کامل نیز با `measurement_scope=profile_route` مشخص می‌شود؛ قوانین direct همان پروفایل می‌توانند مقصد سنجش را مستقیم عبور دهند. این نتیجه اثبات عبور از یک outbound خاص نیست. نسخه و اثرانگشت اعلام‌شده Agent نیز جای امضای انتشار و بررسی امنیتی باینری را نمی‌گیرند.
