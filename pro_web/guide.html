🚀 شروع کار و افزودن سرور

۱. باز کردن ربات

روی Start بزنید و از «سرورهای من» وارد بخش افزودن سرور شوید.

۲. انتخاب روش آسان

نام سرور، IP یا دامنه و پورت SSH را ثبت کنید. مقدار پورت متداول 22 است ولی باید از سرویس‌دهنده خود بپرسید.

۳. مشخصات ورود SSH

نام کاربری و رمز SSH سرور را وارد کنید. برای نصب ایجنت، دسترسی root یا sudo بدون درخواست رمز لازم است. رمز را با شخص دیگری به اشتراک نگذارید.

۴. تأیید کلید میزبان

اثر انگشت SHA-256 کلید SSH را از پنل معتبر سرویس‌دهنده یا کنسول VPS بررسی و بعد تأیید کنید. به کلید ناشناس اعتماد نکنید.

۵. تنظیم ایجنت و ذخیره

پورت ایجنت، زمان اعتبار و پوشه سرور را انتخاب کنید. اگر نصب آغاز شد، وضعیت مراحل و علت تغییر مسیر را دنبال کنید.

۶. تأیید ارتباط امن

زمانی نصب موفق است که سرویس اجرا شود و ارتباط WSS/TLS با پنل تأیید شود؛ صرفاً نصب پکیج‌ها کافی نیست.

🛰 نصب و بازیابی Agent

نصب مستقیم: ابتدا سیستم‌عامل، Python، فضا و ابزارهای ضروری بررسی می‌شوند؛ سپس بسته‌های Python از مخازن معمول نصب می‌شوند.

مسیر جایگزین: اگر نصب مستقیم در زمان تعیین‌شده ناموفق شد، سرور اصلی یک مجموعه Wheel سازگار آماده کرده و از طریق SSH/SFTP ارسال می‌کند. هش فایل‌ها بررسی شده و نصب Python بدون ارتباط با PyPI انجام می‌شود.

Xray: در صورت در دسترس نبودن GitHub روی VPS مقصد، سرور اصلی می‌تواند آرشیو نسخه پین‌شده را منتقل کند. هش آرشیو قبل از اجرا کنترل می‌شود.

اگر نصب ناموفق شد: «لاگ Agent» را از صفحه سرور ببینید. برای خطای SSH، پورت و دسترسی sudo؛ برای TLS، گواهی و فایروال؛ برای وابستگی سیستمی، دسترسی به مخازن Ubuntu را بررسی کنید.

توجه: بسته Wheel آفلاین جایگزین همه پکیج‌های سیستمی Ubuntu نمی‌شود. اگر ابزارهایی مثل Python venv یا OpenSSL موجود نباشند و مخزن apt هم دسترس‌پذیر نباشد، باید منبع بسته سیستمی روی سرور فراهم شود.

پروفایل، اعتبار و اشتراک منابع فنی پس از تأیید دعوت از سوی همکار.

📢 کانال، هشدار و زمان‌بندی

۱. مقصد اعلان‌ها را مشخص کنید

ربات را به کانال یا گروه اضافه کنید، حق ارسال پیام بدهید و شناسه عددی آن را در «کانال اعلان‌ها» ثبت کنید.

۲. نوع اعلان را انتخاب کنید

قطعی، مصرف منابع، انقضا، گزارش دوره‌ای یا همه موارد را انتخاب کنید. گزارش کانفیگ و سرور از دسته «گزارش‌ها» ارسال می‌شود.

۳. برنامه ارسال بسازید

از کرون‌جاب‌ها بازه ۱ ساعت، ۳ ساعت، ۲۴ ساعت یا غیرفعال را انتخاب کنید. هر گزارش تنها در صورت وجود داده معتبر ساخته می‌شود.

۴. هنگام قطع دریافت پیام

مجوز ارسال ربات، شناسه کانال/موضوع، دسته اعلان، اعتبار حساب و اجرای کرون را بررسی کنید. در نبود مقصد معتبر، ربات ارسال خصوصی را امتحان می‌کند.

🛰 انتخاب چند Agent و پورت سفارشی

۱. ایران یا خارج

در ثبت هر سرور موقعیت را انتخاب کنید. فقط سرورهای ایرانِ ثبت‌شده واجد شرایط استخر هستند.

۲. انتخاب و رضایت مالک

مالک سرور آن را پیشنهاد می‌دهد و مدیر اصلی تأیید می‌کند. اطلاعات سرور کاربران دیگر بدون مجوز نمایش داده نمی‌شود.

۳. نصب چندتایی

مدیر در «استخر Agentها» سرورهای خودش را تیک می‌زند و پورت فعلی یا پورت خودکار را انتخاب می‌کند. نتیجه هر نصب در صف قابل مشاهده است.

۴. سنجش واقعی سلامت

فقط Agent دارای ارتباط WSS/TLS و توکن معتبر برای تست انتخاب می‌شود. در برخورد پورت، هیچ سرویس ناشناسی خودکار متوقف نمی‌شود.

۵. روش بالانسر

در تنظیمات مدیر، بر اساس RTT اتصال Agent، مصرف CPU یا ترکیب آن دو انتخاب کنید. اندازه‌گیری مستقل سرعت اینترنت هنوز موجود نیست.

۶. بررسی ایران‌اکسس

از جزئیات سرور، تست چندمسیره را اجرا کنید. نتیجه «احتمال محدودیت از خارج» با «قطعی کامل» متفاوت است.

🌐 ورود مستقل به پنل وب

از گفت‌وگوی خصوصی ربات گزینه «پنل گرافیکی» را انتخاب کنید. کد یک‌بارمصرف را در صفحه ورود HTTPS وارد کنید. این کد پس از ۸ دقیقه یا یک بار استفاده منقضی می‌شود؛ برای ورود مجدد کد جدید بگیرید.

وب‌سایت با کوکی HttpOnly و محدودیت CSRF محافظت شده است. کد را در عکس، لینک، کانال یا گروه منتشر نکنید.

در پنل می‌توانید سرور، کانفیگ و مانیتور HTTP/TCP ثبت کنید. عملیات پرداخت یا مدیریت خطرناک SSH همچنان فقط در ویزاردهای تأییدشده ربات موجود است.

❓ پرسش‌های متداول

چرا Agent نصب می‌شود ولی اتصال برقرار نیست؟

نصب پکیج‌ها با تأیید WSS/TLS متفاوت است. پورت Agent، فایروال، ساعت سرور، گواهی TLS و لاگ systemd را بررسی کنید.

اگر اینترنت ایران کند یا قطع باشد چه می‌شود؟

پس از شکست نصب مستقیم، مسیر انتقال آفلاین Python اجرا می‌شود. سرور اصلی و اتصال SSH بین دو سرور باید برقرار باشد؛ در قطعی کامل شبکه نصب از راه دور امکان‌پذیر نیست.

آیا هم‌گروهی نیاز به تأیید دارد؟

بله. هر دو کاربر باید ربات را شروع کنند. با قبول دعوت، منابع فنی و دسترسی‌های مربوطه مشترک می‌شوند؛ برای اتصال فقط به افراد قابل‌اعتماد درخواست دهید.

آیا رتبه بهترین کانفیگ تضمینی است؟

خیر. رتبه بر اساس Ping، jitter و سنجش ثبت‌شده محاسبه می‌شود. نتایج ممکن است با تغییر مسیر شبکه متفاوت شوند.

اگر نصب وسط راه قطع شود، چه کنم؟

ابتدا گزارش آخرین مرحله را بخوانید، سپس «نصب/رفع ایجنت» را مجدداً اجرا کنید. قبل از نصب مجدد روی سرور عملیاتی بکاپ بگیرید.
