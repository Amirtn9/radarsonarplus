🛰 استخر Agentهای ایران

مدیر اصلی می‌تواند از Agentهای ثبت‌شده و فعال سرورهای ایران استفاده کند؛ دیگر کاربران فقط به منابع فضای کاری خود دسترسی دارند. پورت باز به‌تنهایی به معنی Agent سالم نیست؛ WSS، گواهی و توکن جدا بررسی می‌شوند.

🧩 نصب چندتایی Agent

آخرین عملیات نصب

📊 مصرف ارتباطی Agentها (فقط مدیر)

آمار واقعی بایت‌های WSS و تونل SSH، بدون ادعای اندازه‌گیری دانلودهای مستقل Xray یا کل ترافیک VPS. ثبت اطلاعات نمونه‌برداری است.

🔌 آزمایش اتصال چند پورت

پورت‌های رایج و پورت ثبت‌شده همان سرور بررسی می‌شوند؛ این کار پورت یا Agent را تغییر نمی‌دهد.

🩺 مرکز عیب‌یابی مدیر

گزارش‌های سیستم فقط برای مدیر اصلی در دسترس‌اند. خروجی اطلاعات حساس رایج را حذف می‌کند، اما قبل از اشتراک‌گذاری آن را بررسی کنید.
